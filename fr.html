外向型 (E人)

如果您鍾意多識新朋友、鍾意麵對面同人傾計 → 行街開發適合您

  • 實地走訪商家
  • 面對面溝通建立信任
  • 即時解決客戶疑問

行街開發時機

  • 吃飯、買東西時，發現店家只收現金 → 由支付系統切入
  • 看到店舖有做減價、店裡冇客 → 由跨業引流切入
  • 看到店舖有會員優惠、充值優惠 → 由消費劵鎖客切入
  • 行街看到任何有興趣的店家 → 即興發揮

網上推廣時機

  • 社群媒體看到有店家做任何宣傳 → 由KOL探店、跨業引流切入
  • 每天用程式自動找行業商戶 → 發一般宣傳稿切入
  • 網上看到任何有興趣的店家 → 即興發揮

1. 建立熟悉感 (信任和關係)

  • 介紹我們是甚麼，為何在這，為何和你說話
  • 找話事人(店主、店主的老婆、店長)
  • 在話事人放鬆不忙的情況下，閒聊建立熟悉感
  • 找準重點，瞭解店家真實核心需求

2. 建立吸引力 (滿足需求)

  • 首先要知道他們需求點，不是講我們有甚麼用
  • 講我們那一個點的功能，可以解決他那一個點的問題
  • 成交前只說一個他最重視的點，不說其他，避免複雜化

3. 成交

  • 即場教(話事人懂操作手機) 或 幫(話事人不懂操作手機) 開戶
  • 建立帳戶資料
